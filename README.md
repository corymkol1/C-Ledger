# Small Business Bookkeeper

A command-line bookkeeping application written in C for managing
small-business financial transactions.


<span style="color:red">Visit Screenshots Folder to See it in action</span>


## Features

- Add income and expenses
- Categorize transactions
- Search transaction records
- Edit and delete transactions
- Calculate total income and expenses
- Calculate net profit or loss
- Save transactions between sessions
- Export transactions to CSV

## Technologies

- C
- Structs
- Pointers
- File I/O
- Binary file storage
- CSV generation
- String manipulation

## Compile

gcc -Wall -Wextra -Wpedantic src/bookkeeping.c -o bookkeeper

## Run

./bookkeeper
